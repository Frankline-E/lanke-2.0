For a pnpm monorepo + Neon PostgreSQL + Drizzle ORM, I recommend restructuring packages/db so that Drizzle schema and migrations live inside the database package, while the Neon connection is handled by @neondatabase/serverless.

Drizzle officially supports Neon through its neon-http and neon-websockets drivers; neon-http is a good default for typical serverless queries.

    import { neon } from '@neondatabase/serverless';
    import { drizzle } from 'drizzle-orm/neon-http';

    const databaseUrl = process.env.DATABASE_URL;

    if (!databaseUrl) {
      throw new Error(
        'DATABASE_URL is not defined. Make sure your Neon database connection string is configured.'

    This follows Drizzle's recommended Neon HTTP setup using neon() and drizzle({ client: sql }).
